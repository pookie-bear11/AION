# AION

A frontend-only gamified productivity RPG built with HTML, CSS, and vanilla JavaScript.

## Required folder structure

AION/
│
├── index.html
│
├── css/
│   ├── style.css
│   ├── dashboard.css
│   ├── quests.css
│   └── responsive.css
│
├── js/
│   ├── app.js
│   ├── data.js
│   ├── player.js
│   ├── quests.js
│   ├── inventory.js
│   ├── leaderboard.js
│   └── storage.js
│
└── assets/
    ├── icons/
    └── images/

## Features

- Dashboard
- Quest board with filters/search
- Create and complete quests
- XP and level progression
- Daily Drop reward
- Streak tracking
- Badge unlocking
- Collectibles
- Seasonal leaderboard
- Profile
- Statistics
- Settings
- localStorage save/reset
- Responsive mobile layout
- Loading screen, confirmation, validation, hover/transition effects

## Run

Open `index.html` in a browser. If your browser blocks ES modules on `file://`, use VS Code Live Server.

The visual assets in `assets/images/` were taken from the team's AION presentation to keep the website aligned with the PPT's fantasy purple/gold visual identity.
